# Scrapers (`scripts/scraping/`)

Each weekly pipeline's first step calls one of these (`scrape_tt`, `scrape_bb`, `scrape_ff` in `scripts/weekly_pipeline.py`), then `update_broadcasts`.

- **Titled Tuesday** (`update_titled_tuesday.py`): finds new events on chess.com's completed-tournaments listing page, scrapes the standings pages, then enriches new usernames via the chess.com PubAPI. `titled_tuesday_standings.date` is `TIMESTAMPTZ` on Postgres; write `pd.Timestamp(f'{date} 00:00:00+00:00')`, not a string, which Postgres refuses to implicit-cast.
- **Bullet Brawl** (`update_bullet_brawl.py`): chess.com has no Bullet Brawl listing page, so it finds each new event in the monthly game archives of the most frequent recent players, confirms it against the tournament API, then enriches new accounts with at least `MIN_APPEARANCES` games into `player_information`. If no archive has the event yet, the step fails with `listing_missing_slug` and the Pipeline page takes the URL.
- **Freestyle Friday** (`update_freestyle_friday.py`): a normal chess.com live tournament, `freestyle-friday-{month}-{dd}-{yyyy}-{id}`. Events are discovered the same way (regulars' archives, confirmed as a finished chess960 Swiss on a Friday), and standings are parsed with Titled Tuesday's `fetch_standings`. The chess.com/events page for it renders client-side and isn't used.
  - History: weekly from 2025-01-24 to 2026-06-26, then from 2026-10-02 after a July–September 2026 hiatus (2026-05-08 was cancelled). Five events (US/EU daylight-saving mismatch weeks) started at 12:00 ET, an hour after the spec's start time.
  - `--backfill --start <month> --until <month>` walks back through regulars' archives across empty months. Without `--until` it stops after two empty months, so it would stop at the hiatus.
  - `scripts/push_bullet_brawl_history.py --market freestyle_friday` copies the local history to Railway.
- **Broadcasts** (`update_broadcasts.py`): parses Lichess monthly PGN dumps into `other_events` / `other_event_rounds` / `other_event_participants` (retrospective: games already played), then rebuilds `attendance_conflicts` with `scripts/build_attendance_conflicts.py`. A conflict there is a round on the same UTC date as the event, for a player matched by normalised name.
- **Usernames keep chess.com's capitalization** in every table, one spelling per account. The tournament API lists Bullet Brawl players in lowercase, so ingestion takes the case from the player's games, then adopts the spelling already on record (`src/bullet_brawl_ingest.py`, `known_usernames`: Titled Tuesday first, then `player_information`). Never lowercase usernames; compare case-insensitively when checking whether an account exists.
- **chess.com web pages behind Cloudflare** (e.g. chess.com/events) can't be scraped. Don't add stealth or challenge-solving. `api.chess.com` (the public API these scrapers use) is fine.
